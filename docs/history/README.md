# History

Dated research narratives, retractions and dead ends. **Current truth does
not live here**: see `../formats/<system>.md` for what is true today and
`../systems-coverage.md` for the state of every system.

Files in this directory:

- `<system>.md` - the chronological research log for one system, moved
  verbatim from `formats/<system>.md` once the current-state section is
  rewritten at the top.
- `sessions.md` - the STATUS-handoff session log.

Rules for writing here:

- Keep dates and evidence (capture names, addresses).
- Retractions stay where they were made; do not rewrite history.
- A conclusion that still stands gets promoted into the current-state doc,
  not duplicated here.
